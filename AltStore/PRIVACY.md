# プライバシーポリシー（文字起こし）

最終更新日: 2026年10月11日

「文字起こし」（以下「本アプリ」）は、利用者の情報を次のとおり扱います。

## 開発者が集めるもの

ありません。本アプリには広告、アクセス解析、クラッシュレポートの仕組みは入っておらず、開発者のサーバーにデータを送ることはありません。

## 端末の中に保存するもの

- 取り込んだ音声ファイル、解析結果（発話の区間と波形）、文字起こしの結果、カットやメモ
- 利用者が入力した OpenAI の API キー（端末のキーチェーンに保存）

これらは端末の中だけに保存され、アプリを削除すると消えます。

## OpenAI に送るもの

利用者が文字起こしを実行したときに限り、選んだブロックの音声を、利用者自身の API キーを使って OpenAI の API（api.openai.com）に送ります。送った音声の扱いは OpenAI のポリシーに従います。

- [OpenAI のプライバシーポリシー](https://openai.com/policies/privacy-policy/)
- [OpenAI の API データの扱い](https://openai.com/enterprise-privacy/)

文字起こしを実行しない限り、音声が端末の外に出ることはありません。
